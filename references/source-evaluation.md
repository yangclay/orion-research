# 来源可信度评估（Source Evaluation）

## 可信度等级定义

| 等级 | 标签 | 含义 | 判断标准 |
|------|------|------|---------|
| A | ✅ 高度可信 | 可直接引用 | ≥2 个独立来源证实 + 官方/学术来源 |
| B | ⚠️ 基本可信 | 可参考 | 单源但来源权威 + 逻辑自洽 |
| C | ❓ 存疑 | 需验证 | 有矛盾或来源不明确 |
| D | ⚡ 不可信 | 不建议引用 | 与已知事实矛盾或来源明显偏颇 |

## 判断要素

1. **来源类型**：一手来源 > 二手来源 > 三手来源
   - 一手：论文、官方文档、原始数据、当事人陈述
   - 二手：媒体报道、分析文章、评论
   - 三手：摘要、转述、AI 生成内容

2. **时效性**：信息是否过时？
   - 动态事实（CEO、股价、版本）必须验证日期
   - 静态事实（理论、定义）时效性较弱

3. **利益相关**：来源是否有立场偏差？
   - 竞品推荐、厂商软文、营销内容需标注
   - 独立评测、学术文献可信度更高

4. **交叉验证**：是否有多源印证？
   - 单一来源即使权威也需标注
   - 多源一致才标记 A 级

5. **可追溯性**：能否追溯到原始来源？
   - 有 URL、有 DOI、有原始数据 → 高可信
   - 模糊引用、"据传"、"据说" → 低可信

## 常见来源类型评估

| 来源类型 | 典型可信度 | 备注 |
|---------|-----------|------|
| 学术论文 | A | 同行评审，但需注意时效性 |
| 官方文档 | A | 一手信息，最可靠 |
| 官方财报/文件 | A | 法律约束，需核实 |
| 权威媒体（Reuters/AP） | A | 但需注意立场 |
| 行业分析报告 | B | 可能有商业利益 |
| 技术博客/公众号 | B | 质量参差不齐 |
| 社区讨论（Reddit/HN） | B-C | 需交叉验证 |
| 新闻聚合/SEO 内容农场 | C-D | 低质量高发区 |
| AI 生成内容 | D | 不可作为证据来源 |
| 匿名博客 | C-D | 无法追溯 |

## 伪独立来源检测

**常见陷阱**：10 个网页都引用同一篇 Reuters/AP/官方报告 → 实际只有 1 个独立来源

**检测方法**：
1. 检查引用链：多个来源是否都指向同一原始文章？
2. 检查发布时间：是否为同一时间批量发布？
3. 检查措辞相似度：是否为同一原文复制？

**正确做法**：将来源聚类到原始 source，并按 source family 计数
